รายการอุปกรณ์ประจำรถพยาบาลฉุกเฉิน (Master Equipment List)

สามารถเพิ่มอุปกรณ์ใหม่เข้าสู่ระบบ รายการจะอัปเดตลงตารางชีททั้ง 3 คันอัตโนมัติ

ลำดับ ชื่อรายการอุปกรณ์ เกณฑ์/จำนวนมาตรฐาน หมวดหมู่ สถานะ

จัดการผู้ใช้งานและการอนุมัติสิทธิ์ (User & Access Control)

ผู้ดูแลระบบสามารถอนุมัติผู้ใช้งานใหม่ หรือเปลี่ยนสถานะผู้ใช้งานได้จากหน้านี้

User ID / Email ชื่อ-นามสกุล ตำแหน่ง ระดับสิทธิ์ ต้องเปลี่ยนรหัส สถานะการอนุมัติ การจัดการ

การตั้งค่าระบบและการเชื่อมต่อ Google Sheets

โครงสร้างชีทอัตโนมัติ 5 แผ่นงาน

1. พยาบาลที่3 - ตารางเช็คประจำเดือน คันที่ 3 (วันที่ 1 - 31)

2. พยาบาลที่4 - ตารางเช็คประจำเดือน คันที่ 4 (วันที่ 1 - 31)

3. พยาบาลที่5 - ตารางเช็คประจำเดือน คันที่ 5 (วันที่ 1 - 31)

4. CheckLogs - ฐานข้อมูลประวัติการตรวจเช็คทั้งหมด พร้อมค้นหาและส่งออก PDF

5. EquipmentMaster & Users - จัดเก็บอุปกรณ์และรายชื่อเจ้าหน้าที่

สำหรับผู้ใช้งาน iPhone / iPad (Safari):
  1. แตะปุ่ม แชร์ (Share ) ด้านล่างของ Safari
  2. เลื่อนลงและแตะเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen )
  3. แตะ "เพิ่ม" (Add) มุมบนขวา

กำลังตรวจสอบสถานะ...
ระบบจะตรวจสอบการเชื่อมต่อไปยัง Google Apps Script อัตโนมัติ

* ได้จากการกด Deploy (ทำให้ใช้งานได้) -> New Deployment -> Web App ใน Apps Script ของ Google Sheet

ขั้นตอนการนำขึ้น GitHub & เชื่อมต่อ Google Sheet:
  1. อัปโหลดไฟล์โปรเจกต์นี้ทั้งหมดขึ้นบน GitHub Repository
  2. ไปที่แท็บ Settings -> Pages ใน GitHub แล้วเลือก Deploy จาก Branch main
  3. ใน Google Sheet ไปที่ Extensions -> Apps Script นำโค้ด Code.gs ไปวางแล้วกด Deploy as Web App (สิทธิ์: Everyone)
  4. คัดลอก URL ของ Web App มาวางในช่องด้านบนนี้แล้วกด "บันทึกและเชื่อมต่อ"
